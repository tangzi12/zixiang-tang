# Zixiang Tang — Founder Profile

A responsive, English-language founder profile for investor and collaboration conversations. Built as a static site for GitHub Pages with no build step.

## Published profiles

- [Zixiang Tang](https://tangzi12.github.io/zixiang-tang/)
- [Jake Lu](https://tangzi12.github.io/zixiang-tang/jake-lu/) — technical leadership, scientific model optimization, and Gemini-related model quality work.

## Files

- `index.html` — profile and source references
- `styles.css` — responsive styling and print styles
- `favicon.svg` — monogram favicon
- `assets/zixiang-tang-founder.jpg` — founder portrait
- `.nojekyll` — enables buildless GitHub Pages hosting
- `jake-lu/index.html` and `jake-lu/profile.css` — Jake Lu's team profile

## Preview

Run a static server in this directory, for example `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Publishing

Publish the directory contents at the root of a GitHub Pages repository. All local file URLs are relative, so the site also works under a project path such as `https://username.github.io/founder-profile/`.

## Editorial notes

The profile omits employment dates, graduation years and degree level. Career and project participation statements are based on information provided by Zixiang Tang. Public AWS links provide project context; they are not presented as independent proof of personal attribution. Bio Discovery wording is restricted to early related technology work during his Amazon tenure and does not claim involvement in the later product launch. No unconfirmed metrics, customers, clinical results or wet-lab validation are included.

Primary references:

Typography uses Georgia and system sans-serif fallbacks, with DM Sans loaded from Google Fonts when available. The site requires no JavaScript, analytics, tracking, account system or third-party application integration.
